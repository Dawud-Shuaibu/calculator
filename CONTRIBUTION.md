# Contributing to Calculator Web

Thank you for your interest in contributing! 🙌 This project is open to everyone, and your help will make it even better.

## How to Contribute

### 1. Found a Bug?
  - Open a new issue with:
  - A clear title
  - Description of the bug
  - Screenshots (if applicable)
  - Browser info (if applicable)

### 2. Adding Features or Fixing Bugs

1. Fork the repository
2. Create a new branch: 
3. Make your changes
4. Test thoroughly.
5. Commit with clear message.
6. Push to your fork.
7. Open a Pull Request with:
 - A clear title and description.
 - What you changed and why.
 - Screenshots/GIFs if it's a visual change.
